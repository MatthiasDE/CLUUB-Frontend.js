# AGENTS.md - AI Agent Development Guide

This document provides guidance for AI agents working on the lean CLUUB Frontend project. CLUUB is a non-profit-making association management web application.

## Project Overview
**Project Name:** CLUUB Modular Frontend  
**Type:** Web application that is consuming FastAPI REST APIs.  
**Purpose:** Frontend for time booking, time administration, and member management.  
**License:** AGPLv3+  
**Language:** Python 3.11+  
**Package Manager:** npm  


## Guiding Principles
- Keep the codebase modular and clean
- Keep the codebase and documentation small (keep it short and stupid)
- Utilize the given APIs only that are developed from another agent in another repository
- Avoid unnecessary libraries and dependencies. If you need to use a library, make sure it is well-maintained, widely used, and has a good reputation and get user approval before adding it to the project.

## Implemented Functionality

### Screen 1: Time Recording & Administration
Management of association should be able to have an input interface to record the hours of work for the association for all members. Interface should be lean. Only four fields:
- Selection of member via fuzzy search function of /api/v1/members endpoint and drop-down field with the results automatically fetched when at least 5 characters are entered.
- Selection of start date and time for work done via date and time picker.
- Selection of end date and time for work done via date and time picker.
- Free text field with the max. 140 characters for operations done.
- The bottom of the screen must show all recorded hours for all members that has a start date of today.

### Screen 2: Member Management
- Management of association should be able to create a new member.

### Screen 3: List Members
- List all members in a plain table that can be sorted by id, first name, name
